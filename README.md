# 🎮 Flexarion - Site Vitrine & crowMaster

Bienvenue sur le dépôt officiel du site vitrine du studio **Flexarion**, créateurs du jeu vidéo **crowMaster**.

Ce projet est hébergé via **GitHub Pages** avec domaine personnalisé et optimisé pour le référencement (SEO), la vitesse de chargement et le partage sur les réseaux sociaux (Open Graph).

---

## 🌟 À propos du Studio

**Flexarion** est un studio indépendant de développement de jeux vidéo. Notre mission est de concevoir des expériences immersives et captivantes, emmenées par notre titre phare : **crowMaster**.

---

## 📂 Structure du Projet

L'arborescence est organisée pour garantir une compatibilité optimale avec GitHub Pages tout en conservant des assets bien séparés :

```text
Flexarion-Jeu/
│
├── 📁 .vscode/                 # Configuration de l'environnement de travail
├── 📁 assets/                  # Ressources graphiques et feuilles de style
│   ├── 📁 images/              # Images, logos et médias du site
│   └── 📁 style/               # Feuilles de style CSS
│
├── about.html                  # Page "À propos" (Équipe & Histoire)
├── betaSignup.html             # Page d'inscription à la Bêta de crowMaster
├── CNAME                       # Configuration du domaine personnalisé
├── contact.html                # Formulaire et page de contact
├── crowMaster.html             # Page de présentation du jeu crowMaster
├── error.html                  # Page d'erreur personnalisée (404)
├── google93955eaf2f39f2bd.html # Fichier de vérification Google Search Console
├── index.html                  # Page d'accueil officielle
├── README.md                   # Documentation du projet
└── sitemap.xml                 # Sitemap XML pour l'indexation Search Console
