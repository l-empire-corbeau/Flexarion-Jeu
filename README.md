# 🚀 Flexarion — Site Vitrine

Bienvenue sur le dépôt du site web officiel de **Flexarion**, studio indépendant de développement de jeux vidéo, créateur du projet **Hololive-Xarion**.

---

## 📌 À propos

Ce projet est un site vitrine moderne et fluide conçu pour présenter le studio, l'équipe et l'avancement du jeu *Hololive-Xarion*.

### Fonctionnalités
- 🎨 **Design sombre & moderne** avec effets de survol et halo lumineux (*glow*).
- 📱 **Interface responsive** adaptée aux ordinateurs, tablettes et smartphones.
- 📬 **Formulaire de contact** intégré.
- 🚫 **Page 404 personnalisée** pour la gestion des erreurs de navigation.

---

## 🛠️ Technologies utilisées

- **HTML5** — Structure sémantique et accessibilité.
- **CSS3** — Custom properties, Flexbox, animations et effets visuels modernes.
